# 项目内容

- `engine/`：草稿生成、时间线编辑、资源校验和导出。
- `bridge/`：编解码桥接源码、文件快照和目录锁定。
- `skills/agent-jianying-edit/`：Agent 调用入口、计划编译器和操作文档。
- `docs/media/`：工程交接演示。
- `licenses/`：第三方许可证，详见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

剪映安装包、官方程序库、字体、效果资源、账号数据和用户素材需单独准备。
编解码组件从本仓库源码在本机编译，组件身份和固定哈希由现有校验流程检查。
